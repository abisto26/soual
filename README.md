# سؤال خفيف ضريف مع Abisto

Quick, fun questions from Abisto's videos, in Moroccan Darija. 15 seconds a question, 10 questions a game.

**▶ Play: [abisto26.com/sual](https://abisto26.com/sual/)**

- **أنا اللي غنجاوب**: you answer, then the answer shows.
- **أنا اللي غنسوّل صحابي**: you ask your friends; only you see the answer.
- Get half or more right to win the 🏅.
- Works offline and can be added to your home screen.

Follow **@abisto26** on [Instagram](https://www.instagram.com/abisto26) · [Facebook](https://www.facebook.com/abisto26) · [TikTok](https://www.tiktok.com/@abisto26) · [YouTube](https://www.youtube.com/@abisto26)

## Files

```
index.html     the game (generated)
questions.js   the questions: [question, answer]
src/           the source of the page
build.js       rebuilds index.html and sw.js  →  node build.js
```
